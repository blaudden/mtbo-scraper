# src/utils/

Small, focused utility modules used across the scraper.

## Contents

- `country.py`: ISO country code resolution from federation names.
- `crypto.py`: Email encryption/decryption utilities.
- `date_and_time.py`: Formatting and parsing dated strings, timezone handling.
- `diff.py`: Logic for comparing event data to identify updates.
- `fingerprint.py`: Participant fingerprinting for start list change detection.
- `seeding.py`: Competition rules seeding order calculation for Svenska Cupen.
